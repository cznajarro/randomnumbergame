A command-line random number guessing game

# Overview
A simple command-line number guessing game in Python. The program picks a number from 1 to 100
and the user gets 5 guesses to guess the number. The program will tell you if the previous guess
is higher or lower than the answer.

This was some practice for Python control flow, handling input, and the structure of a program.

# Languages Used
* Python 3

# How to Run
* 1. Make Sure Python3 is installed first
```bash
python3 --version
```

* 2. Clone this repo and go to where you saved it
```bash
git clone https://github.com/cznajarro/randomnumbergame.git
cd randomnumbergame.py
```

* 3. Run the program
```bash
python randomnumbergame.py
```

# Example
```python
Guess a number 1- 100:34
Too high!
Guess a number 1- 100:12
Too low!
Guess a number 1- 100:20
You're right! You win!
```
